# cse341-# CSE341 Contacts API

A simple REST API built with Node.js, Express, and MongoDB Atlas.

## Features
- Create contact (POST)
- Get all contacts (GET)
- Get single contact (GET)
- Update contact (PUT)
- Delete contact (DELETE)

## Base URL
https://cse341-contacts-42r1.onrender.com

## Endpoints

### Get all contacts
GET /contacts

### Get one contact
GET /contacts/:id

### Create contact
POST /contacts

### Update contact
PUT /contacts/:id

### Delete contact
DELETE /contacts/:id

## Tech Stack
- Node.js
- Express
- MongoDB Atlas
- Render (deployment)
